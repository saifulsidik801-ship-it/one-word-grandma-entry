Entrants send exactly one word: the word their grandma would text about AI. A judge model compares words two at a time and the funniest, most grandma-like word wins.

Our word is **gibberish** — grandma's one-word verdict on AI itself: "it's all gibberish to me." Warm, baffled, funny in one word with no context needed, and tied to the AI's language.

## Run it

```sh
python3 main.py
```

It writes the single word to `/output/entry.txt` (9 bytes, no trailing newline).
